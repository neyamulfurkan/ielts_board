What is the Schema? Every day, Claude MUST end its response with a strict [SESSION_DATA]...[/SESSION_DATA] block. This website parses that block to automatically update your tracker. The schema below defines every field — its format, meaning, and example. Claude's prompt includes these rules, so it knows exactly what to produce.
Session Data Schema
🔒 Block Format (required exactly)
Claude must always end its response with this exact structure:

[SESSION_DATA]
field_name: value
field_name: value
...
[/SESSION_DATA]

Rules:
• Each field on its own line. Format: key: value
• No blank lines inside the block
• Multiple values separated by | (pipe with spaces)
• No markdown, no bold, no asterisks inside the block
• All fields must be present every session, even if value is none
📋 All Fields
dayREQUIREDinteger 1–365Example: day: 14
phaseREQUIREDinteger 1–4Example: phase: 1
weekREQUIREDinteger 1–52Example: week: 2
scoreREQUIREDinteger 0–100Example: score: 78
band_estimateREQUIREDdecimal x.0 or x.5Example: band_estimate: 6.5
topic_coveredREQUIREDtext, no pipeExample: topic_covered: Articles and Determiners
errors_grammarREQUIREDpipe-separated or noneFormat: WRONG ==> CORRECT :: REASON — Example: errors_grammar: "a university" ==> "a university" (correct, u sounds like 'y') :: 'a' before consonant sound, not consonant letter | "discuss about" ==> "discuss" :: 'discuss' is transitive, no preposition needed
errors_vocabREQUIREDpipe-separated or noneFormat: WRONG ==> CORRECT :: REASON — Example: errors_vocab: "big impact" ==> "significant impact" :: avoid informal adjectives in academic writing | "affect" ==> "effect" :: affect=verb, effect=noun
errors_writingREQUIREDpipe-separated or noneFormat: WRONG ==> CORRECT :: REASON — Example: errors_writing: "no overview paragraph" ==> "add overview after intro" :: IELTS Task 1 requires overview summarising main trend | "repeated 'increase' 4 times" ==> "use: rise, surge, climb" :: lexical variety improves band score
vocab_learnedREQUIREDpipe-separated or noneExample: vocab_learned: prevalent | substantial | consequently | albeit | mitigate
writing_task_doneREQUIREDyes | noExample: writing_task_done: yes
writing_bandREQUIREDdecimal or naExample: writing_band: 6.5
speaking_doneREQUIREDyes | noExample: speaking_done: yes

media_todayREQUIREDtitle | platform | url_or_searchExample: media_today: 6 Minute English - Memory | BBC Sounds | bbc.co.uk/sounds

Example: notebooklm_task: FLASHCARDS — Upload English Grammar in Use Ch 70-75. Generate 20 cards on article rules (a/an/the/zero), IELTS academic examples only. Bring back any card missed twice.
spacerspacerA second feature may be added after a semicolon if the topic warrants it, e.g. ...; MIND MAP — same source, centre node "Article Rules", branches a/an/the/zero, sub-branches for exceptions.

❌ Common Mistakes Claude Must NOT Make
• Do not use markdown inside the block (no **bold**, no # headers)
• Do not use newlines inside a single field value
• Do not skip any field — all 18 fields must appear every session
• Do not add extra text after [/SESSION_DATA]
• Do not use commas to separate multi-values — use | (pipe)
• Do not put the block anywhere except at the very end of the response
• Do not write score: 78/100 — just write score: 78
